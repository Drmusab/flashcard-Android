Native AnkiDroid supplies card audio, collection persistence, rating/Undo, rendering, navigation and recording. The proposed EN/AR interpreter, voice turn guard and verified Bluetooth routing remain bounded future additions. Their absence is not justification for porting the source application graph.

Source SpeechTextPreprocessor expands cloze and strips selected HTML with regex. Native rendered-side/TTS/AV semantics must remain authoritative for cloze, typed answers, RTL and hidden answers. Later AI narration needs a separate consented input boundary.

Revalidate native answer side even if the interpreter reports RATING_EXPECTED. No direct scheduler write, second FSRS, remote queue or parallel persistence may bypass these seams. [Verification plan](FSA-01A-VERIFICATION-PLAN.md) defines prospective tests; no target voice behavior is implemented or certified.
