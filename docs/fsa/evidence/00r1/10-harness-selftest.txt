## what the harness guarantees for the CI run
- one TSV row per command: label, command, git SHA, branch, OS, JDK vendor/version, Gradle version, exit code, duration, UTC start, failure category, log path;
- logs are verbatim build output (no filtering, no rewriting);
- non-zero exits are propagated (a failed step fails the job), so a skip can never be reported as a pass.
